# Baizhi Work（MonkeyAI / 百智办公）

百智办公是面向团队的开源 AI 办公工作台，用自然语言完成办公、编程与设计任务，支持共享模型、知识库、技能、MCP 和规则，以及权限管理、使用审计和私有化部署。

- 官网：https://work.baizhi.cloud/
- 文档：https://work.docs.baizhi.cloud/
- 源码及许可证：https://github.com/chaitin/MonkeyCode （AGPL-3.0）
- 本模板基于官网安装入口提供的服务端在线包 v26111301，使用其中固定版本的公开镜像。应用镜像支持 Linux amd64 和 arm64，至少需要 1 核 CPU、1 GB 内存。

## 部署

在 Portainer 的 Docker Standalone 环境中选择本模板，并填写以下变量。此模板不适用于 Docker Swarm。

| 变量 | 说明 |
| --- | --- |
| MONKEYAI_PUBLIC_URL | 用户访问的完整地址，包含协议及非标准端口；生产环境使用 HTTPS，并与反向代理的外部地址一致。 |
| MONKEYAI_INITIAL_ADMIN_EMAIL | 首次创建的管理员邮箱。 |
| MONKEYAI_INITIAL_ADMIN_PASSWORD | 首次创建的管理员强密码，无预设密码。 |
| POSTGRES_PASSWORD | 数据库密码；使用独立生成的 64 位十六进制字符串，避免数据库连接 URI 中的特殊字符。 |
| RUSTFS_SECRET_KEY | 对象存储密钥；使用另一个独立生成的 64 位十六进制字符串。 |
| MONKEYAI_BIND_IP | HTTP 监听地址，默认 127.0.0.1；只需受信任局域网访问时可改为服务器的局域网 IP。 |
| MONKEYAI_HTTP_PORT | 主机 HTTP 端口，默认 8080。 |

分别运行两次 `openssl rand -hex 32` 生成数据库密码和对象存储密钥。不要重用管理员密码。密码保存在 Portainer 的堆栈配置及容器环境中，应限制 Portainer、Docker 和备份的访问权限，不要公开填写后的配置。

默认仅向主机回环地址发布 HTTP；对外使用前，请在同一主机配置 HTTPS 反向代理，转发至 127.0.0.1:8080（或所选端口），并支持 WebSocket 升级和长连接。不要将未加密的登录页面直接暴露到互联网。此模板不分发官方安装器的共用自签名证书或私钥。

初始化服务只对本堆栈的数据卷设置 UID/GID 10001:10001 和目录权限，不挂载主机目录或 Docker socket。数据库就绪后执行迁移；对象存储和迁移完成后启动后端，后端健康后启动管理界面。数据库和对象存储端口不向主机发布。

首次登录后，按官方文档配置模型和团队资源。初始化管理员变量仅用于首次创建账户，不用于重置已有账户的密码；可在初始化完成后移除这两个变量并同步修改堆栈中的对应环境配置。此模板的升级由 Portainer 管理，不应再对同一实例混用官方主机安装器。

## 数据与备份

PostgreSQL、对象存储及日志、运行身份、许可证、导入临时文件和 ACME 状态使用堆栈隔离的命名卷。运行身份卷包含服务端身份和签名私钥，许可证卷包含机器标识，升级和重建时必须保留；删除堆栈时不要同时删除这些卷。定期备份数据库及相关数据卷，备份应限制访问并加密保存。

连接外部模型或工具时，相关数据可能发送至相应服务；私有化部署不等于所有数据都不出网。免费版及商业版的具体权益以官网为准。
